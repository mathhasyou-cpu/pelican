# Глоссарий

Термины в том значении, в каком их использует код, интерфейс и техдока АС ПЕЛИКАН. У
каждого термина — где он определён (источник истины). Английские эквиваленты — те, что
стоят в полях JSON и в коде.

## Предметная область: сигналы и их оценка

| Термин | Значение | Источник |
|---|---|---|
| **Слабый сигнал** (weak signal) | Зарождающаяся технология с низкой видимостью при росте (Yoon 2012; зарождающаяся — Rotolo, Hicks & Martin 2015). С выключенными флагами термин равен «кандидат класса `emerging` с соответствием запросу 2–3, попавший в ТОП-15». Три слоя «уже тренд / слабый сигнал / зарождающееся» (`weak/layers.py`) — за флагом `WEAK_LAYERS`, который на стенде включён решением владельца (`OQ-17`); в слоях «слабый сигнал» уже, чем ТОП: не тренд и подтверждён двумя независимыми путями | `docs/techdoc.md` §1, §6, §10; `weak/layers.py` |
| **Направление** (direction) | Единица выдачи: технология плюс названные игроки, а не отдельная статья. В коде — `Signal`. Слово имеет в наборе три смысла: этот (единица выдачи, `Signal`), «направление запроса» (фасет, раздел «Запрос и его раскрытие») и «направление сигнала» (`Signal.facet`, там же); в тексте требований смысл уточняется словом рядом | техдока §1 |
| **Кандидат** (candidate) | Направление, извлечённое из научного или денежного потока и доведённое до оценки зрелости; до оценки — `_Cand`, после — `Signal`. До 45 на запрос (`weak/ask.CANDIDATES`) | `weak/ask.py` |
| **Ярлык** (label) | Английское имя направления (язык корпуса и новостей); показывается до прихода русского названия | `Signal.label` |
| **Название** (title) | Русское имя направления, которое модель даёт на стадии карточек или через событие `titles` | `Signal.title` |
| **Ядро технологии** (core) | Короткое имя приёма, на котором стоит направление («federated learning» для «federated learning for fraud detection»); по нему считается след в корпусе и сливаются близнецы | `weak/core.py`, техдока §6 |
| **Варианты** (variants) | Написания одного приёма, сведённые в один кандидат (UPGMA, порог 0.78 эмбеддера) | `Signal.variants`, техдока §5 шаг 2 |
| **Поток** (stream) | Откуда пришёл кандидат: «наука» (работы корпуса) или «деньги» (новости о раундах, пилотах, сделках) | `Signal.stream` |
| **Класс зрелости / жанр** (kind) | Один из шести классов ТЗ: `emerging` зарождающаяся технология; `mature` зрелая (массовое внедрение, сформированный рынок, выраженные лидеры); `standard` отраслевой стандарт или спецификация; `hype` маркетинговый хайп без технического содержания; `noise` информационный шум, не технология; `too_broad` слишком общая категория. Порядок проверки — `too_broad, noise, hype, standard, mature, emerging`; в выдачу идёт только `emerging`. Ключ `kind` имеет в наборе три смысла: этот (`Signal.kind`, класс зрелости), тип источника (`Source.kind`, раздел «Источники и доверенность») и вид в событии `verdict` (`kind = "error"` — не оценено) / вид задания в прототипе (`jobs.kind = 'article'`, `focus.kind`) | `weak/kinds.py` |
| **Вердикт** (verdict) | Результат оценки зрелости одного кандидата: класс, стадия, причина, компании; событие `verdict` | `events.py`, `weak/assess.py` |
| **Фильтр мейнстрима** | Отсев всех классов, кроме «зарождающейся», с причиной словом ТЗ; «схема 1 ТЗ» | техдока §5 шаг 6 |
| **Стадия** (stage; стадия зрелости) | Не путать со стадией прогона (раздел «Очередь, задания, события»). Самая продвинутая ступень, которую показывают свидетельства, по рубрике заказчика: `концепция/исследование` → `прототип/poc` → `пилот` → `раннее внедрение`. Ровно четыре канонические ступени. В выдаче ступень ставит лестница вех (см. «Вехи стадии»), в том числе ниже выбора модели; выбор модели (`stage` оценки) остаётся признаком модели. У оценки старого формата без вех — пол по прочитанному: есть продажи — не ниже раннего внедрения, есть пилот — не ниже пилота (BR-15) | `weak/rubric.evidence_stage`, `weak/rubric.stage_floor`, `page.HINTS["stage"]` |
| **Вехи стадии** (stage milestones) | Три чтения оценки, по одному на ступень: `prototype_built` (прототип построен), `pilot_with_customer` (пилот у названного заказчика), `generally_available` (продукт общедоступен). Ступень выдачи — старшая прочитанная веха; ни одной — концепция/исследование. Приём — лестница проверяемых вех (TRL; RAIL, arXiv:2608.13428; CheckEval, arXiv:2403.18771) | `weak/assess.JUDGMENTS`, `weak/rubric._STAGE_LADDER` |
| **Чтения оценки** (judgments) | Двенадцать проверяемых по свидетельствам ответов того же вызова оценки зрелости: `players_named`, `funding_mentioned`, `commercial_deployment`, `pilot_mentioned`, `market_leaders_named`, `routine_tool`, `standard_or_regulation`, `field_not_technology`, `novelty_claimed` и три вехи стадии. Признаки `J` модели этапа 1; `funding_mentioned`, `commercial_deployment` и `pilot_mentioned` — ещё и входы-кандидаты модели роста (`weak/model.QUERY_COMMERCE`), поэтому их смысл не переопределяется | `weak/assess.JUDGMENTS` |
| **Тренд** (trend) | Вторая шкала рубрики («растёт» / «растёт быстро»). Предсказывается только в оценке на датасете (`scripts/measure_signal_kinds.py`); живой конвейер (`weak/ask.py`) тренд не выдаёт — по замеру хуже константы | `weak/rubric.py`, техдока §11 |
| **Балл методолога** | Стадия (1–4) + тренд (2–3) = 3…7; используется только при оценке на датасете | `weak/rubric.score` |
| **Соответствие запросу** (relevance) | 0–3 по шкале UMBRELA: 3 прямо о предмете; 2 смежное (материалы, инструменты, инфраструктура, на которые предмет опирается); 1 могла бы применяться; 0 другая отрасль. В ТОП — только 2 и 3; ниже 2 — исключение классом «шум» (BR-04); в порядок и уверенность не входит | `weak/topic.py`, `page.HINTS["relevance"]`, `RELEVANCE_LABELS` |
| **Не о предмете** (offtopic) | Не класс, а причина исключения: кандидат с соответствием < 2 получает класс `noise` и причину «Свидетельства не о предмете запроса «…»» (`weak/ask._on_topic`), карточка — штамп «снято: не о предмете» (`Card.jsx`). Группа `offtopic` в сводке исключённого (`format.js excludedKey`) собирается только у отчётов, где исключённый кандидат остался `emerging` | `weak/ask._on_topic`, `web/src/lib/format.js`, `BR-04` |
| **Уверенность модели (роста)** (confidence) | Калиброванная вероятность, что за два года научный след ядра вырастет сильнее, чем в среднем по области; L1-логистическая регрессия `weak/growth.json` с одним признаком `query_share_pct` — перцентиль доли свежих работ ядра среди кандидатов запроса. По ней — порядок ТОП. Это не соответствие запросу | `page.HINTS["confidence"]`, техдока §5 шаг 7, §7 |
| **Уверен** (confident) | Сигнал с уверенностью > 0.75; KPI «с уверенностью выше 75 %» | `jobs.summary_of`, `page.HINTS["confident"]` |
| **Ключевые предикторы** (predictors) | Три наибольших по модулю слагаемых уверенности (вес × z-значение признака), «за» и «против». Не постфактум-объяснение, а разложение той же суммы | `page.HINTS["predictors"]`, техдока §7 |
| **Качество свидетельств** (evidence share) | Доля пройденных именованных проверок карточки (`Check.counted`). В долю не входят условие попадания в ТОП «жанр: зарождающаяся» (`entry=True`) и подпись «несколько независимых игроков» (`scored=False`): условием ТОП подпись не является (`Signal.shown` смотрит только на класс) | `page.HINTS["evidence"]`, `weak/ask.Check`, `weak/ask.Signal.shown` |
| **Проверка свидетельств** (check) | Именованный вопрос «да/нет» по карточке. В долю входят четыре: «разные типы источников» — источники ≥ 2 типов из `INDEPENDENT_KINDS` (все не-корпусные источники: научные публикации, препринты, государство, университеты, ассоциации, отраслевые медиа — статьи включаются; пресс-релизы, блоги, агрегаторы — нет); «научная опора» — ≥ 2 работы с ядром в тексте; «разные издатели» — новости ≥ 2 разных доменов; «объяснение со ссылками». Ещё две вне доли: «жанр: зарождающаяся» (`entry=True`) и «несколько независимых игроков» (`scored=False`) — см. «Качество свидетельств» | `weak/ask.Check`, `weak/ask.INDEPENDENT_KINDS` |
| **След в корпусе** (footprint) | Для ядра и для ярлыка: число работ и год первого появления в корпусе; доля работ за последний год; полнотекстовый поиск `tsvector @@ tsquery` | `weak/core.py`, техдока §3, §6 |
| **Низкая заметность** (low visibility) | Видимость направления ниже медианы пула запроса (перцентиль, приём BERTrend) | техдока §7 |
| **Устойчивость / «держится N из K»** (held, stable) | В скольких из последних K прогонов того же запроса (до `weak/history.HISTORY_RUNS = 5`) есть то же направление. Согласие выдачи с собой, не качество; в порядок и уверенность не входит. KPI «держатся в ≥ половине из N прошлых прогонов» | `page.HINTS["held"]`, `weak/history.py`; см. `OQ-02` |
| **Гипотеза** (hypothesis) | Одно «если …, то …» для эксперта, построенное только на процитированных источниках карточки, помечено как сгенерированное; ветка схемы 1 ТЗ «сигнал найден → генерация гипотезы» | техдока §7 |
| **Объяснение «почему это слабый сигнал»** (why) | Одна фраза модели со ссылками `[n]` на свидетельства; предложение без ссылок отбрасывается. У исключённого — «почему исключено» | `page.HINTS["why"]`, `weak/card.py` |
| **Цитата-подтверждение** (why quote) | Дословный фрагмент источника при объяснении; показывается, только если найден в тексте процитированного свидетельства (приём ALCE, Gao et al. 2023) | техдока §5 шаг 9 |
| **Компании / «Кто это делает»** (companies) | Компании, названные в рыночных новостях о направлении (до 4 в вердикте); сверяются с текстом заголовка, выдуманные отбрасываются | `page.HINTS["companies"]`, техдока §5 шаг 3 |
| **Хронология** | Датированные факты из источников карточки (раунды, пилоты, релизы) | `web/src/components/Card.jsx` |
| **Кейс для банка** (case) | Пример применения направления в банке, написанный моделью по свидетельствам | ТЗ 7.2, `tz.test.jsx` |
| **Оценки в аналитических материалах** | Секция карточки: резюме источников типов регулятор / ассоциация / университет / отраслевое медиа и патенты; если таких нет — об этом сказано | ТЗ 7.2, `tz.test.jsx` |

## Выдача и её части

| Термин | Значение | Источник |
|---|---|---|
| **ТОП** (top, signals) | Первые 15 (`weak/ask.TOP`) зарождающихся направлений с соответствием ≥ 2, по убыванию уверенности | `AskResult.signals` |
| **Вне ТОП / тонкие** (thin) | Зарождающиеся направления, не вошедшие в ТОП-15 по уверенности | `AskResult.thin`, `page.HINTS["thin"]` |
| **Исключённое** (excluded) | Кандидаты классов `mature`, `standard`, `hype`, `noise` (в том числе не о предмете запроса, BR-04), `too_broad`; у каждого причина | `AskResult.excluded`, `page.HINTS["excluded"]` |
| **Наблюдать** (watch) | Зарождающееся без двух независимых подтверждений; слой выдачи за флагом `WEAK_LAYERS`, на стенде включённым (`layer_reason`, `OQ-17`) | `weak/layers.py`, флаг |
| **Не оценено** (unassessed) | Кандидат, на котором модель оценки зрелости отказала; в выдачу не идёт, называется в отказах | техдока §11, событие `verdict` с `kind = "error"` |
| **Рыночная категория** (category) | Название без единого слова сверх запроса и рыночного словаря; снимается до оценки; KPI «снято как категория» (`categories_removed`) | `weak/tech.is_category`, `page.HINTS["categories"]` |
| **Короткий ТОП** (shortfall) | ТОП меньше 15; на экране — «В ТОП набралось n из 15» и куда ушли кандидаты; «Это не сбой» | `web/src/components/RunNotes.jsx` |
| **Живой поиск** (live search) | Источники, опрашиваемые в момент запроса. `weak/live.search` опрашивает пять: Google News (англ.), Google News (рус.), КиберЛенинка, Хабр, GitHub; отдельно `weak/live.news_many` — Google News по кандидатам и для денежного потока. Патенты EPO (`weak/patents.py`) и аннотации arXiv/OpenAlex (`weak/deepen.py`) — отдельные модули; в «Не ответили» все идут под именами `page.LIVE_NAMES`. Кэш суток | `weak/live.py`, `page.LIVE_NAMES` |
| **Углубление ТОП** (deepen; шаг конвейера) | Досбор текстов для показанных после отбора: аннотации работ пакетным запросом в arXiv/OpenAlex и фактовые заголовки Google News по ядру (`weak/deepen.py`, `weak/ask.deepen_top`). Идёт по остатку бюджета времени (FEAT-19); в уверенность и проверки не входит. Не путать с углублением ветки (раздел «Продолжение исследования») | `weak/deepen.py`, докстринг `weak/ask.py` (п. 7) |
| **Не ответили** (live errors) | Источники живого поиска, отказавшие в этом прогоне, с причиной | `AskResult.live_errors` |
| **Отчёт** (report) | Результат одного прогона: JSON (`AskResult`), HTML отчёта, сводка для истории, список моделей. Имя — время старта `YYYYmmdd-HHMMSS`. Пользователю отчёт отдаётся JSON-ом `GET /api/reports/{name}` и экраном `#report=<name>` | таблица `reports`, `jobs.save_report` |
| **HTML отчёта** | Самодостаточная страница, которую собирает `weak/page.py` при сохранении прогона; хранится в `reports.html`, пользователю не отдаётся — маршрут `/r/{name}` («отчёт одной страницей») снят (`c1c4ea8`) | `weak/page.py`, `jobs.save_report` |
| **Инсайт документом** | Печатный лист одного сигнала: `print.html#report=…&sig=<label>` (ТЗ 7.2) | `web/src/print/Print.jsx` |
| **Версия отчёта** (REPORT_VERSION) | Номер содержимого выдачи; отчёты ниже версии кэш повторов не отдаёт; сейчас 2 | `weak/ask.REPORT_VERSION` |
| **Модели ответа** (models) | Список `{model, role, endpoint}`, записанный в каждый результат, показанный на странице и залогированный | `AskResult.models`, техдока §9 |

## Источники и доверенность

| Термин | Значение | Источник |
|---|---|---|
| **Источник** (source) | Документ, на который опирается карточка: `n`, наименование, ссылка, издатель, дата, тип, язык оригинала, уровень доверенности, русское резюме с пометкой машинного | `weak/ask.Source`, ТЗ |
| **Тип источника** (kind; смысл `Source.kind`) | Одно из: научная публикация; препринт; государство / регулятор; университет / научный центр; отраслевая ассоциация / международная организация; отраслевое медиа; компания-разработчик; пресс-релиз; блог / соцсеть / агрегатор; репозиторий кода; патентная база | `weak/trust.py` |
| **Уровень доверенности** (trust level) | По домену издателя: `high` высокая (наука, препринты, патенты, государство, университеты, ассоциации); `medium` средняя (отраслевые медиа, вендоры, GitHub); `low` пониженная (пресс-релизы, блоги, соцсети, агрегаторы); `unknown` не оценена (домена нет в списках). Неизвестное не поднимается до средней | `weak/trust.py` |
| **Издатель** (publisher) | Домен, по которому считается доверенность; у Google News ссылка — переадресация, поэтому берётся домен издателя, а не ссылки | `weak/trust.corroborated` |
| **Подтверждено / «не единственное основание»** (corroborated) | У карточки есть хотя бы один известный источник уровня выше пониженного; иначе пометка «пониженная доверенность» в строке ТОП и в карточке | `weak/trust.corroborated`, ТЗ |
| **Машинное резюме** (machine summary) | Русское резюме источника, написанное генеративной моделью; у иностранного — «машинное резюме на русском, оригинал на языке источника», у русского — «резюме сгенерировано моделью» | техдока §8 |

## Запрос и его раскрытие

| Термин | Значение | Источник |
|---|---|---|
| **Запрос** (query) | Направление в свободной форме по-русски, ≥ 3 символов после схлопывания пробелов | `api.ask` |
| **Примеры ТЗ / запросы замера** (TZ queries) | Четыре запроса `measure_ask.TZ_QUERIES`: «технологии в ИИ», «перспективные решения в финтехе», «слабые сигналы в области кибербезопасности» (три дословно из ТЗ) и «космические технологии и новые материалы» (далёкий от датасета домен). Кнопками на главную вынесены три из ТЗ (`Home.jsx EXAMPLES`) | `scripts/measure_ask.TZ_QUERIES`, `web/src/screens/Home.jsx` |
| **Направление запроса / фасет** (facet) | Одно из ~6 конкретных направлений внутри области, на которые модель раскрывает запрос (`facets_ru`, `facets_en`); сектор радара, буквы А, Б, В… | техдока §5 шаг 1, событие `facets` |
| **Подрынок** (submarket) | Компоненты, оборудование, услуги, сертификация и т. п. внутри области; шаблоны денежного потока | `weak/ask.SUBMARKETS` |
| **Направление сигнала** (`Signal.facet`) | Индекс фасета, назначенный после сведения: научному кандидату — фасет, давший больше всего работ; остальным — ближайший по косинусу. Порога нет, сектор есть всегда; на отбор и порядок не влияет | техдока §5 «Направление кандидата» |
| **Query drift** | Уход расширенного запроса от предмета пользователя; предотвращается правилами раскрытия | техдока §5 шаг 1 |

## Очередь, задания, события
