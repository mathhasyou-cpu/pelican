## 2. Краткое описание

Аналитик с любого экрана одним сочетанием клавиш открывает окно поиска и команд: действия
текущего экрана, переходы, последние отчёты, поиск отчёта по тексту запроса и запуск нового
запроса. Ценность: не нужно искать кнопку на экране; всё под рукой и с клавиатуры.

## 3. Предусловия

- Веб-интерфейс открыт. История может быть не загружена — тогда группы отчётов пусты.

## 4. Триггер

Ctrl+K (⌘K на macOS) — по коду клавиши `KeyK`, поэтому работает и в русской раскладке;
либо кнопка «Поиск и команды» в шапке.

## 5. Основной поток

1. Аналитик нажимает Ctrl/⌘+K.
2. Система открывает модальное окно `<dialog>` «Поиск и команды» с полем «Найти отчёт,
   команду или задать новый запрос», фокус в поле, фон под вуалью; повторное Ctrl/⌘+K
   закрывает окно.
3. Без ввода система показывает группы по порядку: команды текущего экрана (если экран
   их задал через `setCommands`), «Переходы» («Новый запрос», «История запросов»,
   «Руководство»), «Последние отчёты» — три самых новых (запрос, дата).
4. Аналитик вводит текст. Система фильтрует все группы по подстроке без учёта регистра и
   добавляет: «Оформление» («Светлая тема»/«Тёмная тема», «Оформление: Газпромбанк» /
   «Оформление: АС ПЕЛИКАН»), «Отчёты» — до шести совпавших по тексту запроса; при вводе
   ≥ 3 символов — «Новый запрос» → «Найти сигналы: <текст>» с подсказкой «N мин» (медиана
   истории, без неё 17 — `T.typicalRun`).
5. Аналитик выбирает пункт стрелками ↑↓ (циклически) или наведением мыши и нажимает Enter,
   либо кликает по пункту.
6. Система закрывает окно и выполняет действие: переход (`navTo`), открытие отчёта
   (`openReport`), запуск запроса (`startJob` → UC-01), переключение темы или бренда
   (UC-12), команду экрана (в UC-04 — группа «Этот отчёт»: «Поделиться ссылкой на
   отчёт», «Сохранить PDF», «Показать радаром»/«Показать столом», при вводе — группа
   «Направления»: «Только «<направление>»» (`Report.jsx setCommands`); в UC-02 — группа
   «Этот прогон»: «Скопировать ссылку на ожидание» (`Wait.jsx`)).

## 6. Альтернативные потоки и исключения

- **A1. Закрыть без действия.** Esc, клик по вуали или повторное Ctrl/⌘+K закрывает окно.
- **A2. Ничего не нашлось.** Список пуст → «Ничего не нашлось. Наберите хотя бы три буквы —
  и запрос можно будет запустить».
- **A3. Команды экрана.** Экран (UC-02, UC-04) регистрирует свои команды через
  `app.setCommands(fn)`; при смене экрана они сбрасываются (`App.jsx`: `commands.current =
  null` в эффекте по `hash`).
- **A4. Истории нет.** Группы «Последние отчёты»/«Отчёты» отсутствуют; остальное работает.
- **E1. Отказ запуска запроса.** Действие «Найти сигналы» ведёт в UC-01; отказ API (422,
  429, сеть) показывается тостом по UC-01.

## 7. Постусловия

- Успех: выполнено выбранное действие; окно закрыто.
- Отмена: состояние не изменилось.

## 8. Особые требования

- NFR-09 (сочетание по коду клавиши, `<dialog>`, стрелки, Enter, Esc), NFR-06 (без ввода
  показываются только три отчёта, чтобы окно помещалось без прокрутки; с вводом список не
  ограничен — до 6 отчётов, команды экрана, 3 перехода, 2 оформления и «Найти сигналы»;
  `.cmdk-list` без `max-height` (`app.css`), окно растёт по содержимому, выбранный пункт
  подводится `scrollIntoView({block: "nearest"})`), NFR-12 (действия открытия отчёта идут
  через `navTo`, адрес меняется; пункты переходов и отчётов — `<a role="option" href>`:
  Ctrl-клик, ⌘-клик и средняя кнопка открывают новую вкладку, обычный щелчок выполняет
  пункт на месте; команды без адреса — ссылки без `href`).
- Подпись сочетания в подвале окна: «Ctrl K» или «⌘ K» по платформе (`format.js MAC`).
- Доступность: `role="combobox"`, `aria-activedescendant`, `role="listbox"/"option"`.

## 9. Точки расширения и включения

- Расширяет UC-01 (запуск запроса из палитры), UC-04 (команды отчёта), UC-02 (ссылка на
  ожидание), UC-09 (переход к истории и к отчёту), UC-11 (переход к руководству), UC-12
  (тема и бренд).

## 10. Данные и интерфейсы

- Компонент `web/src/components/CommandPalette.jsx` (`items(q) → [{group, label, hint,
  icon, run, href?}]`, `ref.open()/close()`); список строит `App.jsx items(q)`.
- Константы: без ввода — 3 отчёта, с вводом — 6 (`App.jsx items`); порог нового запроса —
  3 символа (`App.jsx`, согласован с `api.ask` «запрос короче трёх символов»); подсказка
  длительности — `lib/timeline.js typicalRun` (медиана 20 последних отчётов, без истории
  `DEFAULT_RUN_S = 1020` — копия `jobs.DEFAULT_RUN_S`).
- Отчёты берутся из `app.sorted` (история, новые сверху); дата — `fmtStarted`.
- Внешних вызовов нет, кроме действий, которые делегируются другим сценариям.
