## 2. Краткое описание

Аналитик читает полную карточку одного направления — сигнала из ТОП, зарождающегося вне
ТОП, «наблюдать» или исключённого — и проверяет каждое утверждение по пронумерованным
источникам. Карточка — «инсайт» по ТЗ: описание, преимущество, кейс для банка, объяснение
статуса и уверенности с цитатой, гипотеза, хронология, компании, оценки аналитики,
проверки свидетельств, след в корпусе и источники с наименованием, ссылкой, датой, типом,
языком, доверенностью и русским резюме.

## 3. Предусловия

- Отчёт открыт (UC-04) и выбран сигнал (`current`), либо открыт печатный документ одного
  сигнала (UC-08, `&sig=`).
- У сигнала есть поля `Signal` из `src/pelican/weak/ask.py`; часть полей может быть пустой
  (старый отчёт, сбой на стадии карточек) — карточка обязана это назвать (`BR-25`).

## 4. Триггер

Выбор строки стола, точки радара, пункта списка, строки исключённого, клавиши ↑↓←→ в
UC-04; открытие ссылки `#report=<name>&sig=<label>`; открытие `print.html#…&sig=<label>`.

## 5. Основной поток

Секции в порядке `web/src/components/Card.jsx`; «условная» — показывается только при
наличии данных или при классе `emerging`.

1. Система показывает шапку карточки: русское название (`title`), под ним английский ярлык
   и варианты написания (`label`, `variants`), ряд чипов: штамп («сигнал» для `emerging` с
   соответствием ≥ 2; «снято: не о предмете» для `emerging` с соответствием < 2; «снято:
   <kind_label>» для остальных классов), стадия подписью с заглавной (`stageLabel`),
   «поток: наука|деньги» (условно), «держится в <held> из <history_runs> прошлых прогонов»
   (условно, `held > 0`; K — `rep.history_runs`, проп `runs` карточки).
2. **«Уверенность модели роста»** (условно: только `emerging`): полоса и процент
   (`pct(confidence)`, жёлтая при > 0.75), предикторы одним плоским списком `predictors[]`
   с маркером «– » (`system.css .preds li::before`); слова «за» / «против» и знак вклада —
   часть строки бэкенда («<признак> — за|против (±вклад)», `weak/model.phrase`), на группы
   карточка их не делит (`BR-10`).
3. **«Почему это слабый сигнал»** (у исключённого — **«Почему исключено»**): фраза `why`
   со ссылками `[n]`; у исключённого, чьё объяснение снято без ссылки, `why` — причина из
   чтений оценки «По признакам оценки: …» (`ask.excluded_why`, UC-03 шаг 8, `BR-03`); при
   пустом `why` — «Объяснение не сверено с источниками: статус
   держится на признаках уверенности выше и проверках свидетельств ниже.»; при наличии
   `why_quote` — цитата блоком (`BR-22`).
4. **«Соответствие запросу»** (условно: `relevance` задано): «<r> из 3 — <подпись из
   `RELEVANCE`>» и причина `relevance_why` со ссылками (`BR-04`).
5. **«Что это»** (условно: `description` непусто): текст со ссылками.
6. **«Потенциальное преимущество»**: текст со ссылками; при пустом у `emerging` —
   «В свидетельствах карточки преимущество не названо.»; у исключённого при пустом секция
   не показывается.
7. **«Кейс для банка»** (условно: `case` непусто).
8. **«Хронология»** (условно: `facts` непуст; свёрнута в режиме `fold`): даты и факты со
   ссылками, счётчик в заголовке.
9. **«Кто это делает»** (условно: `companies` непуст): чипы компаний (`BR-21`: только
   найденные в заголовках).
10. **«Оценки в аналитических материалах»** (свёрнута в `fold`; счётчик в заголовке —
    число таких источников плюс 1 при непустом `patents` — показывается только в режиме
    `fold`, `Card.jsx Section`): резюме источников типов
    «государство / регулятор», «отраслевая ассоциация / международная организация»,
    «университет / научный центр», «отраслевое медиа» с издателем, датой и ссылкой `[n]`;
    строка «Патенты: <patents>» (условно); если ни одного — «Среди прочитанных источников
    нет аналитики, регуляторов или отраслевых медиа об этой технологии.»
11. **«Гипотеза для проверки»** (условно: `hypothesis` непусто): одно «если …, то …» со
    ссылками.
12. **«Проверки свидетельств»** (условно: `checks` непуст; свёрнута): «k из n» в
    заголовке (только в режиме `fold`); каждая проверка со статусом пройдено/нет, пояснением
    и пометкой «(условие входа)» только у «жанр: зарождающаяся» (`entry`; в методике
    печатного отчёта — «условие входа в топ»); «несколько независимых игроков» — подпись без
    пометки, в долю уверенности не идёт (`scored = False`). Счётчик «k из n» считает только
    проверки доли (`Check.counted`: без `entry` и `scored = False`), как `evidence_share`.
13. **«След в корпусе»** (условно: `core` непусто; свёрнута): «ядро «<core>»: <core_works>
    работ с <core_since>, доля за последний год <pct> — низкая заметность» (последнее —
    условно).
14. **«Источники»** (всегда, кроме режима `compact`; свёрнута в `fold`): вид выбирается
    режимом `fold`, не шириной окна — при `fold` (карточка справа в отчёте, UC-04) список
    (`SourcesList`), без `fold` (печать, UC-08) таблица «№ / Источник / Дата / Тип / Язык /
    Доверие» (`SourcesTable`). У каждого: наименование ссылкой (только http(s)), издатель,
    дата или «не указана» («дата не указана» в списке), тип (`kind`), язык (`lang`),
    доверенность (`trust_label`), русское резюме с пометкой «(машинное резюме)» при
    `machine_summary`; у иностранного без резюме — «русского резюме нет» (`BR-18`).
15. Аналитик щёлкает ссылку `[n]` в любом тексте. Система раскрывает свёрнутый раздел
    «Источники», прокручивает к строке `n` и подсвечивает её (`BR-26`); наведение на `[n]`
    показывает заголовок источника, издателя и дату.
16. Аналитик щёлкает наименование источника — открывается оригинал в новой вкладке
    (`rel="noopener noreferrer"`).

## 6. Альтернативные потоки и исключения

- **A1 (шаг 14). Режим `compact`** (без раздела источников, используется вне отчёта):
  ссылки `[n]` остаются текстом, раздел «Источники» не показывается.
- **A2 (шаг 14). Печатная карточка** (UC-08): все секции развёрнуты (`fold` выключен),
  источники таблицей.
- **A3 (шаг 15). Номер без такого источника** (например, `[99]` в тексте, а источника
  `99` нет): остаётся текстом, не ссылкой (`BR-26`).
- **A4 (шаг 16). Ссылка источника не http(s)** (`javascript:`, `ftp:`, пусто):
  наименование показывается текстом без `<a>` (`BR-24`, `NFR-53`).
- **A5 (шаг 1). Сигнал вне ТОП / исключён.** Штамп карточки — по классу: «сигнал» у
  `emerging` с соответствием ≥ 2 (в том числе у `thin` и «наблюдать»), иначе «снято: …».
  Подпись места над карточкой одна на экран и печать (`format.js placeOf`): «№ k из n в
  топе», `excluded` — «исключено», `thin` и «наблюдать» — «вне топа». Секция «Уверенность модели роста»
  есть только у класса `emerging`.
- **A6 (шаг 3). Исключённый без объяснения.** В отчётах, собранных конвейером с
  `excluded_why`, у исключённого `why` непусто всегда (UC-03 шаг 8). Пустое `why` бывает у
  старых отчётов: секция «Почему исключено» с текстом «Объяснение не сверено с
  источниками…» — причина класса видна по штампу (`scripts/retext.py` дописывает такие
  причины в сохранённые отчёты, UC-29).
- **E1. Отчёт старого формата** (нет `relevance`, `hypothesis`, `facet`, `why_quote`):
  условные секции не показываются; карточка остаётся корректной.
