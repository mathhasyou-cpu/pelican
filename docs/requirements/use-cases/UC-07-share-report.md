## 2. Краткое описание

Аналитик передаёт коллеге отчёт одной ссылкой: на экран отчёта в интерфейсе (с
сохранением выбранного вида стол/радар, выбранного сигнала, раскрытого исключённого и
закреплённого направления — всё это экран держит в адресе `#report=…&view=…`) или на ещё
идущее ожидание (чтобы коллега видел тот же прогон). Получатель открывает ссылку без
очереди и без заставки поверх отчёта. Отчёт файлом для передачи вне стенда — PDF (UC-08).

## 3. Предусловия

- Для ссылки на отчёт: отчёт открыт (UC-04). Для ссылки на ожидание: открыт экран
  ожидания (UC-02).
- Интерфейс открыт по публичному адресу Funnel (иначе ссылка локальная и коллеге не
  откроется).

## 4. Триггер

Кнопка «Поделиться» в шапке отчёта; команда «Поделиться ссылкой на отчёт» в палитре
(UC-10); кнопка «Ссылка на ожидание» на экране ожидания; копирование адреса из строки
браузера (экран отчёта держит в нём своё состояние, A1).

## 5. Основной поток

1. Аналитик нажимает «Поделиться» на экране отчёта.
2. Система составляет адрес: `location.href.split("#")[0] + "#" + reportHash(...)` (адрес
   страницы до `#`, включая строку запроса `?brand=`/`?theme=`, если она есть, плюс
   текущее состояние экрана — `Report.jsx share`, `reportHash`): `#report=<name>` и
   `&view=radar`, если открыт радар (вид «стол» — умолчание и в ссылку не пишется), а
   также `&sig=`, `&cut`, `&facet=` по A1.
3. Система копирует адрес в буфер обмена (`navigator.clipboard` в безопасном контексте) и
   показывает тост «Ссылка на отчёт скопирована».
4. Аналитик передаёт ссылку. Получатель открывает её.
5. Система получателя показывает короткую заставку (`NFR-14`: `Splash.jsx` держит её
   987 мс, затем затухание `--t-slow` 360 мс и снятие слоя через 400 мс — видна ≈ 1,35 с;
   один раз на сессию вкладки — `sessionStorage pelican-splash`, решение принимает
   `index.html` до первой отрисовки), затем экран отчёта (UC-04) в указанном виде; отчёт
   берётся из `reports` одним `GET /api/reports/{name}` без постановки в очередь и без
   заставки поверх уже показанного отчёта.

## 6. Альтернативные потоки и исключения

- **A1 (шаг 2). Ссылка на конкретный сигнал.** Экран отчёта держит своё состояние в
  адресе (`Report.jsx reportHash`, `history.replaceState`; `NFR-49`): выбранный сигнал —
  `&sig=<label>` (кроме первого, он открыт и так), раскрытое исключённое — `&cut`,
  закреплённое направление — `&facet=<n>`, радар — `&view=radar`. «Поделиться» копирует
  этот же адрес. Получатель видит карточку этого сигнала; если он не в ТОП —
  исключённое раскрыто (`Report.jsx cutOpen`, UC-04 A1). «Открыть как документ» ведёт на
  `print.html#report=<name>&sig=<label>` (UC-08 A1).
- **A2 (шаг 3). Clipboard API недоступен** (`file://`, `http` без безопасного контекста,
  отказ пользователя): система пробует `document.execCommand("copy")` через скрытое
  поле; при неудаче показывает `window.prompt("Ссылка", url)` для ручного копирования.
- **A3 (триггер). Ссылка на ожидание.** На экране ожидания кнопка «Ссылка на ожидание»
  (в палитре — «Скопировать ссылку на ожидание») копирует `location.href` до `#` плюс
  `#job=<id>` — путь и строка запроса страницы, как в UC-02 ш. 3 (`Wait.jsx share`); тост
  «Ссылка на ожидание скопирована». Получатель видит тот же
  прогон с восстановленным радаром (UC-02), а по готовности — отчёт. Кнопка «Отменить»
  видна и получателю, но отменить задание может только автор — адрес, с которого оно
  поставлено: с другого адреса API отвечает 403 «Задание поставлено с другого адреса —
  отменить его может только автор.», тост с этим текстом (UC-02 A7, `NFR-52`).
- **A4 — снято:** маршрут `/r/{name}` убран (`c1c4ea8`).
- **A5 — снято:** интерфейс `/classic` убран (`c1c4ea8`).
- **A6 (шаг 5). Получатель уже смотрит отчёт и открывает ссылку в той же вкладке.**
  Заставка не показывается повторно (сессия вкладки), экран меняется переходом.
- **E1 (шаг 5). Отчёт удалён или имя с ошибкой.** «Такого отчёта нет. Ссылка устарела или
  набрана с ошибкой. Все готовые отчёты — в истории.» (UC-04 E1): `GET /api/reports/{name}`
  отвечает 404 «нет такого отчёта», в том числе на имя вне формата `BR-45` до обращения к
  базе (`jobs.REPORT_NAME`).
- **E2 — снято:** маршрут `/r/{name}` убран (`c1c4ea8`).
- **E3 (A3). Задания по ссылке нет.** `GET /api/jobs/{id}` → 404 → «Такого запроса нет»
  (UC-02 E1).

## 7. Постусловия

- Успех: адрес в буфере обмена получателя действителен; отчёт у получателя идентичен
  отчёту отправителя (один и тот же `reports.result`); никаких изменений в данных.
- Отказ: тост не показан, окно `prompt` с адресом; данные не меняются.

## 8. Особые требования

- `BR-38` (повтор запроса открывает тот же отчёт — ссылка и кэш ведут к одному имени),
  `BR-45` (имя отчёта неизменно при перепрогоне: ссылки живут). `BR-46` (отчёт-документ
  `/r/{name}`) — снято вместе с маршрутом.
- `NFR-12` и `NFR-49` (адресуемость состояний), `NFR-14` (заставка при прямой ссылке
  короче и один раз), `NFR-50`, `NFR-52` (наружу только Funnel; ссылка открыта всем за
  Funnel, аутентификации нет; отмена — только автору), `NFR-62` (имя отчёта — время старта).
- Вид «радар» в ссылке — явный параметр; вид «стол» — умолчание; `localStorage`
  получателя при открытии по ссылке с `view=` не меняется.

## 10. Данные и интерфейсы

- Адреса: `#report=<name>[&view=radar][&sig=<label>][&cut][&facet=<n>]`; `#job=<id>`
  (`web/src/App.jsx` маршруты, `Report.jsx share`/`reportHash`, `Wait.jsx share`).
- `App.jsx copyLink(url, done)`: Clipboard API → `execCommand` → `prompt`; тосты
  «Ссылка на отчёт скопирована» (умолчание), «Ссылка на ожидание скопирована».
- `GET /api/reports/{name}` (`api.report`): `reports.result`; имя вне `jobs.REPORT_NAME` или
  нет строки — 404 «нет такого отчёта». HTML отчёта (`reports.html`, `weak/page.render`)
  пишется при сохранении, но пользователю не отдаётся.
- Имя отчёта — `YYYYmmdd-HHMMSS` (`jobs.save_report`, `NFR-62`); `name` в JSON
  результата отсутствует, клиент добавляет его сам (`api.js report`).
- Заставка: `sessionStorage pelican-splash` и классы `splashing`/`splash-short` на `<html>`
  ставит `web/index.html` до первой отрисовки; удержание — `hold` в
  `web/src/components/Splash.jsx` (987 мс по прямой ссылке `#report=`/`#job=`, 2207 мс
  обычно, 610 мс при `prefers-reduced-motion`), затухание `--t-slow` 360 мс
  (`system.css`), снятие слоя через 400 мс.
