# Дополнительная спецификация

Артефакт RUP «Supplementary Specification»: требования, которые не укладываются в один
сценарий — качество по FURPS+ (функциональность сквозная, удобство, надёжность,
производительность, сопровождаемость), ограничения проектирования, интерфейсы,
безопасность, данные, документация, правовые условия. Вместе с моделью сценариев
составляет SRS.

Атрибуты у каждого требования: приоритет (M/S/C), статус (Р / Ф / Пт / Пр / Снято), проверка.
Числа принадлежат константам кода, названным в колонке «Проверка / владеет».

## 7. Интерфейсы

### 7.1 REST API (`pelican.api`, Swagger `/api/docs`)

| Метод и путь | Параметры | Ответ и коды |
|---|---|---|
| `POST /api/ask` | тело `{"query": str}`; пробелы схлопываются | **422** «запрос короче трёх символов» (< 3 символов; тело не по схеме — 422 валидации FastAPI); **200** `{status:"done", query, report, cached:true}` — готовый отчёт того же запроса версии ≥ `REPORT_VERSION`; **202** снимок задания `{id, query, status, created, started, finished, progress[], error, error_detail, report, cancel, position, eta_start_s}` (+ `typical_run_s` у `queued`/`running`; `cancel` — флаг просьбы об отмене) — новое задание или уже активное с тем же запросом; **429** «с вашего адреса уже 3 запроса в очереди и в работе — дождитесь, пока один из них закончится» |
| `GET /api/jobs/{id}` | — | **200** снимок; у `queued`/`running` дополнительно `stage_typical {stage_id: секунды}` (медиана по последним 20 готовым); **404** «нет такого задания» |
| `GET /api/jobs/{id}/events` | `after` ≥ 0 (курсор `seq`) | **200** `{status, report, error, error_detail, elapsed, next, events:[{...data, seq, at, t}]}`; вид события в `t`; **404** «нет такого задания» |
| `POST /api/jobs/{id}/cancel` | — (автор — адрес клиента, NFR-51) | **200** `{id, status}`: ожидающее → `cancelled` сразу; идущее остаётся `running` с флагом `cancel` и снимается исполнителем на границе стадии (`jobs.Cancelled` → `cancelled`; стадия `save` не прерывается); готовое, упавшее и отменённое не меняются (в ответе их статус); **403** «Задание поставлено с другого адреса — отменить его может только автор.»; **404** «нет такого задания». Отдельной отмены администратору нет |
| `GET /api/history` | `limit` 1..1000 (50), `offset` ≥ 0, `q` (подстрока без учёта регистра, `%`/`_` экранируются) | **200** `{total, items:[{name, query, started, signals, confident, candidates, sources_processed, seconds, excluded, thin, facets}], typical_run_s}` |
| `GET /api/reports/{name}` | имя по `BR-45` (`jobs.REPORT_NAME`) | **200** результат целиком (`AskResult` JSON); **404** «нет такого отчёта» — и для имени вне `BR-45`, без обращения к базе |
| `GET /api/glossary` | — | **200** `{hints:{key: text}, live_names:{key: name}}` |
| `GET /api/queue` | — (читатель — адрес клиента, NFR-51) | **200** `[{status, position, mine, created, started, eta_start_s}]` для `running` и `queued`, идущее первым, ожидающие по `id`; `position` — индекс в списке (у идущего 0), `eta_start_s` — как в снимке (у идущего 0); у своих (`mine`) дополнительно `id`, `query`, `stage` (данные последнего события `stage` или `null`) |
| `GET /api/health` | — | **200** `{status:"ok", worker, last_claim_s, restarts}`; **503** `{status:"down", …}` если поток мёртв или к очереди не обращался дольше 2 × типичного прогона |
| `GET /api/docs`, `GET /openapi.json` | — | Swagger UI и схема OpenAPI (FastAPI; ReDoc выключен); служебный `GET /docs/oauth2-redirect` |
| `/` (статика) | — | `web/dist` (`index.html`, `print.html`, `assets/`), монтируется последней; кэширование — NFR-42; без `web/dist/index.html` не монтируется |
| `POST /top_k` (шард-сервер, хост :8020) | вектор, k | ближайшие работы; `GET /health` |

Планируется (статус Прототип, `prototypes/ui-v2/IMPLEMENTATION.md` §6): `POST /api/ask` с
`parent`, `focus`; `GET /api/threads`, `GET /api/threads/{id}`;
`GET /api/articles?thread=&topic=`, `GET /api/articles/{id}`; `GET/POST /api/topics`,
`PATCH /api/topics/{id}`, `POST /api/topics/{id}/run`. Задания темы ставятся с клиентом
`topic:<id>`, поэтому снять их через `POST /api/jobs/{id}/cancel` с адреса пользователя нельзя
(403 — адрес не совпадает с автором).

Все изменяющие запросы (`POST`) — только со своей страницы (NFR-52): с `Sec-Fetch-Site`
`cross-site`/`same-site` или с чужим `Origin` — **403** «Запрос с чужого сайта отклонён.»
до обработки. Каждый ответ, API и статика, несёт заголовки безопасности `api.SECURITY_HEADERS`.
